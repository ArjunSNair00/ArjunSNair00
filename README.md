## 🛠️ Production Repositories

### 🌌 [NodeScape v1.1.0](https://github.com/ArjunSNair00/NodeScape)
> **Interactive AI-powered spatial knowledge graph explorer.**
* **The Architecture:** `LLM (llama-3.3)` → Structured JSON → Parser Engine → 3D Renderer (`Three.js` + `d3-force-3d`) / 2D Canvas (`Pixi.js`).
* **The Vector:** Guided learning "Path Mode" tracking camera interpolation, hierarchical layered views, and an offline-first glassmorphic workspace interface.

### 🔍 [WhereIsThatImage?](https://github.com/ArjunSNair00/WhereIsThatImage)
> **Local-first semantic image query database.**
* **The Vector:** Natural language imagery search over local multi-media streams via on-device vector embeddings.
* **Stack:** React • FastAPI • OpenCLIP • ChromaDB • PyTorch

### 🌌 [Starfield Tunnel](https://github.com/ArjunSNair00/Starfield-Tunnel)
> **Audio-reactive 3D programmatic performance monument.**
* **The Vector:** Beat-reactive bloom arrays mapped via parsed MIDI timings, mouse-driven gravitational spacetime warping, and network-isolated binary stream asset caching.
* **Stack:** React 19 • Vite 7 • Three.js • @react-three/fiber • Tailwind v4
